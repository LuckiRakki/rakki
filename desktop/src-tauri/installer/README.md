# Installer pictures

The Windows installer's pictures (tauri.conf.json, `bundle.windows.nsis`):

- `sidebar.bmp`, 164 x 314: the left side of the Welcome and Finish pages.
- `header.bmp`, 150 x 57: the top right of every other page, on Windows' white header.

Both are 24-bit BMPs (NSIS takes nothing else). Made from `../icons/icon.png` with Inter; keep the sizes when you swap them for the V2 icons.
