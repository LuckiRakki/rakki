Rakki

Server features for the Rakki app.

Daily Mixes

Six playlists built every night at 12 AM from your library: each one led by a different artist, kept to one kind of music, and mixed 2:2:1 from popular songs (Last.fm), songs you play, and songs that are new to you.

Your own free key from last.fm/api. Shared with the Rakki app for administrators, so it only needs entering once (on either side).
Leave empty to use whoever opens the preview.
How alike two genre tags must be to share a group. Higher makes more, narrower groups; lower joins neighbours (for example Plugg and Cloud Rap) more readily.

Lyrics

Word-by-word lyrics for Rakki and the Spicy Lyrics web mod: read from .ttml files next to your songs (served at /SpicyLyrics/{itemId}/ttml), with the Spicy Lyrics API as a fallback, a nightly scraper for missing files, and lyrics search.

Lyrics: nightly TTML scraper

Optionally fetch missing TTML sidecars from the public LyricsPlus / KPoe aggregator. Runs as a Scheduled Task; default trigger is daily at 3 AM. Run on-demand or change the schedule under Dashboard → Scheduled Tasks → Spicy Lyrics.

e.g. apple,lyricsplus,musixmatch,spotify,qq,deezer,musixmatch-word

Lyrics: Spicy Lyrics API

Fallback for tracks with no .ttml sidecar, using the Spicy Lyrics API. Sidecars always win. Lyrics from the API are cached for speed, refreshed nightly before they are 30 days old, and deleted if a refresh fails for that long, as the API Terms require. Clients show the provider and, for community syncs, credit the uploader and maker.

The API looks lyrics up by Spotify track ID. Tracks are matched to Spotify for free via MusicBrainz, so this works best when your library is tagged with MusicBrainz IDs (e.g. by MusicBrainz Picard or Jellyfin's MusicBrainz metadata). Tracks with no MusicBrainz → Spotify link fall back to line-by-line lyrics. To force a match, set a Spotify provider ID on the track.

Create one at developers.spicylyrics.org. Stays on the server; never sent to apps.
Task: Dashboard → Scheduled Tasks → Spicy Lyrics → Refresh Spicy Lyrics API cache (daily, 4 AM).
